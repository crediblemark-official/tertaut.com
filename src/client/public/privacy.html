Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: 7 Oktober 2026 • Kepatuhan terhadap UU No. 27 Tahun 2022 (UU PDP) & Google API Services User Data Policy

1. Ringkasan Pengendali Data (Data Controller)

Layanan tertaut.com dioperasikan oleh PT Credible Mark Official (berkedudukan di Sleman, D.I. Yogyakarta, Indonesia). Tertaut adalah platform infrastruktur pengembang (Merchant of Record, sistem lisensi kriptografis software Ed25519, dan AI proxy shield). Kami berkomitmen melindungi privasi pengunjung dan pengguna kami secara penuh.

2. Kebijakan Khusus Data Pengguna Google (Google OAuth & API User Data Policy)

Tertaut menyediakan opsi masuk/mendaftar menggunakan Google Sign-In (OAuth 2.0). Bagian ini menjelaskan secara transparan bagaimana data pengguna Google diakses, digunakan, dan disimpan:

A. Data Google yang Kami Akses (Scopes):

Kami hanya meminta scope otentikasi dasar yang tidak sensitif:

  • openid: Untuk mengidentifikasi ID pengguna unik secara aman.
  • email: Untuk membaca alamat email primer pengguna sebagai identitas akun builder.
  • profile: Untuk membaca nama lengkap dan foto profil publik Anda.

B. Tujuan Penggunaan Data Google:

  • Otentikasi login satu klik (Single Sign-On) yang aman ke dashboard Tertaut.
  • Membuat profil builder pengembang dan mengaitkan lisensi serta aplikasi software milik Anda.
  • Mengirimkan notifikasi teknis dan keamanan terkait akun Anda.

C. Larangan Pembagian & Penjualan Data:

Tertaut TIDAK PERNAH menjual, menyewakan, mentransfer, atau membagikan data pengguna Google kepada broker data, jaringan periklanan pihak ketiga, atau entitas komersial luar mana pun. Data Google tidak digunakan untuk penargetan iklan atau pelatihan model AI pihak ketiga.

D. Penyimpanan & Retensi Data:

Data profil disimpan di basis data terenkripsi (TLS 1.3 in-transit, enkripsi rest AES-256). Data disimpan selama akun Anda aktif di Tertaut.

E. Hak Penghapusan Data & Pencabutan Izin:

Pengguna dapat mencabut akses Tertaut kapan saja melalui halaman resmi: Google Account Permissions (https://myaccount.google.com/permissions) . Anda juga dapat meminta penghapusan akun dan seluruh data terkait dengan mengirim email ke: platformtertaut@gmail.com.

Google API Services User Data Policy Compliance Statement (English)

Tertaut's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements.

  • Data Accessed: Basic profile (Google user ID, display name, profile avatar) and primary email address.
  • Purpose: Strictly for user authentication, account creation, and builder profile management within Tertaut.
  • No Data Transfer: Google user data is never transferred or sold to data brokers, third-party advertisers, or external parties.
  • Revocation: Users can revoke access anytime at Google Permissions.

3. Data Transaksi & Pembayaran

Sebagai Merchant of Record, kami memproses transaksi pembayaran digital (QRIS, Virtual Account bank, dsb.) melalui payment gateway berizin resmi Bank Indonesia. Tertaut tidak pernah menyimpan nomor kartu kredit atau PIN perbankan Anda.

4. Data Validasi Lisensi Software (Ed25519)

Untuk memvalidasi kuota seat lisensi software bagi pengembang (builders), kami memproses hash Hardware ID perangkat secara satu arah (one-way HMAC salted hash). Kami tidak mengakses file pribadi, dokumen, atau riwayat penjelajahan di perangkat pengguna akhir.
